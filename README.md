# BibleGrace

Daily Bible Verses, Devotionals & Free Faith Tools

**Live:** https://biblegrace.freshblogs.cc

## Tech Stack
- Astro 4 + React Islands
- Tailwind CSS
- KJV Bible JSON (local, zero API)
- Vercel hosting

## Tools (4 active + 4 coming soon)
1. ✅ Daily Verse — date-seeded daily verse + reflection
2. ✅ Verse Finder — search 100+ verses by 26 topics
3. ✅ Bible Quiz — 40+ questions, 3 difficulty levels
4. ✅ Prayer Generator — 21 prayers across 12 categories
5. 🔜 Verse Card Maker
6. 🔜 Reading Plan Generator
7. 🔜 Bible Timeline
8. 🔜 Name Meaning

## Getting Started
```bash
npm install
npm run dev
```

## Deployment
Push to GitHub → Vercel auto-deploys.
